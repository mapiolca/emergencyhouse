# Accessibilité

La cible est WCAG 2.1 AA. Le portail doit être testé au clavier, avec lecteur
d'écran, à 200 % de zoom et aux largeurs 320, 375, 768, 1024 et 1440 pixels.

Sur smartphone et tablette, tous les champs éditables utilisent une taille
calculée d'au moins 16 pixels. Le viewport laisse le zoom utilisateur actif.
